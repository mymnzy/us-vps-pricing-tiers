## 同样是美国机房，价格为什么能差几十倍

在洛杉矶，1 核 1G 的机器可以从 29 元卖到 87 元，配置完全一样，差的只是回国的路由。有第三方整理文章拆过这笔账，同机房同配置，普通国际线路 29 元，CN2 GIA 87 元，一个月差 58 元。你花的钱有一大半不在 CPU 和内存上。

线路名词先认几个。CN2 GIA 走电信 59.43 段独立路由，有 QoS 保障，晚高峰不容易堵。9929 是联通精品网 AS9929。4837 是联通 AS4837 骨干，去程回程都走它。NTT 和 GTT 是国际 Tier1 运营商，海外方向质量好，回国就是普通线路。双 ISP 说的是 IP 归属被标成住宅运营商，跟线路不是一回事。

延迟方面，美国西海岸到国内普遍落在 150 到 180ms 这个量级。有第三方测评用电信宽带测它的 AS4837 那款，延迟 186ms，晚高峰又单独测了一轮。不同人测、不同时段测，结果会有出入，别把某一个数字当唯一标准。

## 关于美国VPS价格，问得最多的几个问题

### 美国VPS需要备案吗？

不需要。机器在美国机房，不在国内备案范围内，开通就能用。这也是很多人选美国机器而不是香港、内地机房的原因之一。

### 双ISP和原生IP有什么区别？

原生 IP 指 IP 的注册归属地和机房所在地一致，没经过二次分配。双 ISP 指这个 IP 在数据库里被标成住宅宽带运营商，看起来像美国家庭用户而不是机房。六六云这几款主打的都是双 ISP 加原生 IP 段，用在平台账号和流媒体上比普通机房 IP 稳。但第三方测评显示，不同数据库的判断会打架，购买前最好拿测试 IP 自己查一遍。
